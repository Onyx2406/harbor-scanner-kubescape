# Security Policy

## Supported versions

This project is currently maintained as a community integration while it is prepared for donation to the `goharbor` organization. Until a stable release policy is published, please use the latest tagged release.

## Reporting a vulnerability

Please do not open public issues for security vulnerabilities.

To report a vulnerability, email:

**security@nucleus-systems.com**

Please include:

- Affected version or commit SHA
- Clear reproduction steps
- Expected and actual behaviour
- Potential impact
- Any suggested mitigation or patch

We will acknowledge reports as soon as reasonably possible and coordinate fixes before public disclosure.

## Scope

This repository implements a Harbor scanner adapter for Kubescape. Vulnerabilities in Kubescape, `kubevuln`, Grype, Syft, Harbor, or Kubernetes itself should also be reported to the respective upstream project when appropriate.
